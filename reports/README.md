# Reports Directory

This directory contains generated reports that provide insights into the state of the awesome-virome repository.

## Available Reports

### Data Quality

- `data_quality_report.md` - Overview of data quality metrics
- `data_quality_history.json` - Historical data quality metrics

### Metrics

- `metrics_report.json` - Repository metrics including tool counts, categories, etc.

## Notes

These reports are generated by maintenance scripts. The citation-validation and site-health reports were removed in July 2026 along with the citation tracking system and the site-health workflow.
